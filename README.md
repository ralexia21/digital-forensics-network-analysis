# Digital Forensics & Network Traffic Analysis

Academic digital forensics project focused on network traffic investigation and analysis using Wireshark.

## Investigations

### 1. Traffic & Trace Analysis

Analysis of captured network traffic to identify suspicious hosts, communications and potential indicators of compromise.

The investigation included:

- PCAP traffic analysis using Wireshark
- IP and TCP traffic analysis
- HTTP request analysis
- TCP stream investigation
- Identification of suspicious external communications
- Extraction of Indicators of Compromise (IOCs)

### 2. Multi-Stage Malware Traffic Investigation

Investigation of captured network traffic associated with a suspected multi-stage malware scenario.

The analysis included:

- Identification of potentially compromised hosts
- HTTP and TLS traffic analysis
- Investigation of repeated connections to external hosts
- Analysis of suspicious HTTP requests and URI patterns
- TCP stream analysis
- Identification of potential Command and Control (C2) communication
- Documentation of Indicators of Compromise

## Tools & Techniques

- Wireshark
- PCAP analysis
- Network traffic analysis
- TCP/IP analysis
- HTTP analysis
- TLS traffic analysis
- TCP stream analysis
- IOC identification
- Basic malware traffic investigation
